## Weights provenance - a SEPARATE question from the repo licence

A LICENSE file grants rights over **code**. The trained weights are a
different artefact, produced from datasets with terms of their own, and
whether those terms follow the weights is unsettled law.

Checking only the repo licence made UNISAL look like the cleanest
candidate here. Its weights were trained on Hollywood-2 - clips from
commercial feature films. No LICENSE file in a model repo can answer that.

| Model | Weights licence | Trained on | Signal |

- DHF1K: Research dataset

## Why each one is on the list

### UNISAL

- **Paper:** Unified Image and Video Saliency Modelling (ECCV 2020)
- **Repo:** https://github.com/rdroste/unisal
- **Clone:** already cloned
- **Licence file:** LICENSE
- **Verdict:** likely OK for commercial use - confirm

**Why considered:** One small model covering BOTH image and video saliency - our two input kinds from one artefact. Smallest of the candidates, so the most likely to clear the CPU budget.

**Watch out for:** Video mode expects 16-32 consecutive frames at native fps. Our 2 fps samples are not that, so we would use its image mode unless the video path is evaluated separately.

### DeepGaze IIE

- **Paper:** DeepGaze IIE: Calibrated prediction in and out-of-domain (ICCV 2021)
- **Repo:** https://github.com/matthias-k/DeepGaze
- **Clone:** already cloned
- **Licence file:** NONE FOUND
- **Verdict:** BLOCKED - no licence file: default copyright applies, so no permission is granted. An intent stated elsewhere (a commented-out license= in setup.py, a line in a paper) is not a grant - ask the author to add a LICENSE file before relying on it.

**Why considered:** Probabilistic and explicitly principled about centre bias, which matters more for ads than for natural photos.

**Watch out for:** An ensemble - heavy. Check whether a single-branch export is viable.

### UMSI / predimportance

- **Paper:** Predicting Visual Importance Across Graphic Design Types (UIST 2020)
- **Repo:** https://github.com/diviz-mit/predimportance-public
- **Clone:** already cloned
- **Licence file:** LICENSE
- **Verdict:** REVIEW - restrictive wording found

**Restrictive wording found - read this properly:**

- `non-commercial`
- `research purposes only`

**Why considered:** Trained on DESIGNED images - ads, posters, infographics - rather than natural photos. Natural-image saliency systematically under-weights text blocks and logos, which is precisely what an ad report is about. Worth evaluating even if it loses on MIT1003.

**Watch out for:** Predicts 'importance', not fixation. Compare on our ad frames, not on MIT1003.
